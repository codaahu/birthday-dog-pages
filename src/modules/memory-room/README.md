# 回忆小屋

运行 `npm run dev` 后打开独立调试地址。

- [默认探索](http://127.0.0.1:5173/#/dev/memory-room)
- [示例相册和拼图](http://127.0.0.1:5173/#/dev/memory-room?scene=history)
- [本机导入的照片](http://127.0.0.1:5173/#/dev/memory-room?scene=photos)

页面由章节页首、礼物小屋、探索进度和底部小狗对白组成。左上角返回当前入口的上一级，首次主线保留原有线性流程。右上角沿用现有音乐开关，调试时只保存到当前情景的开发档案。音源与可随正式版使用的小狗角色见素材清单。

点墙上相框、相机与日历、电视、书架或餐桌可发现五处主回忆。电视打开 3×3 拼图，点两块交换。首次点餐盘也可打开日常相册，其余餐点、瓶子和饮料杯在原地播放短暂光效。

七类相册共用拍立得手账。横向滑动或轻点底部箭头切换照片，点图全屏查看，双指缩放后可拖动。照片带留言时，点下方的留言标签翻面。关闭全屏会回到相册，关闭相册会回到刚才的小屋物件。示例情景的合照收录三张横竖测试图，右侧书架等入口可查看其他主题。

点小白和小金毛玩偶，停手约 0.4 秒后会打开狗狗秘密相册。可以在弹出前连点，也可以关闭相册继续点同一对玩偶。点其他房间物件会清零本次连续点击。原有搞怪相册从秘密相册里的对白入口打开。

五处主回忆解锁「回忆侦探」，十五处食物与饮料解锁「吃货雷达」，连续摸玩偶五次解锁「摸狗大师」，打开秘密相册解锁「贴贴发现家」，拼好九宫格解锁「回忆修复师」，探索全部二十一处热区解锁「小屋观察员」。新成就通过公共历史事务写入，并在顶部依次显示，每条约三秒。已有成就在重玩后仍保留。

原有主线继续条件沿用有效相册探索和拼图结果，照片探索至多要求三个相册，拼图完成或跳过均可继续。狗狗相册可为空，加入照片到 `materials/photos/pet/` 后运行 `npm run prepare:assets`。

- `Module.vue` 管理探索、面板、草稿、成就和模块完成事件
- `RoomPageFrame.vue` 负责整页构图、页首按钮、实时探索徽章和欢迎对白
- `RoomArt.vue` 按插画边界定位热区，坐标和成就条件见 `room.ts`
- `AlbumViewer.vue` 呈现相册，`AlbumFullscreen.vue` 和 `albumGestures.ts` 处理全屏查看与手势；`PuzzleBoard.vue` 与 `puzzle.ts` 实现拼图
- `materials/scenes/memory-room-scene.png` 是原图，`public/assets/room/memory-room-scene.webp` 是清理标记后的运行图

运行 `npm run test -- src/modules/memory-room` 检查模块逻辑。浏览器内用手机宽度逐个点击物件，再刷新核对探索和拼图记录。

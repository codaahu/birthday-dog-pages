# 通关结算

独立开发预览 [http://127.0.0.1:5173/#/dev/ending](http://127.0.0.1:5173/#/dev/ending)。

执行 `npm run dev` 后打开上述地址。默认使用独立的「首次 · 待确认结算」开发档。点击进入小屋会在此开发档执行真实通关事务，并显示测试提示。刷新可核对成就已保存。在调试大厅的同名场景可重置测试档。[空记录预览](http://127.0.0.1:5173/#/dev/ending?scene=empty) 用于核对缺失数据文案。

- `Module.vue` 是三种运行模式共用的模块入口
- `summary.ts` 用本轮统计、游戏、作品和已揭晓的券生成纪念清单
- `config.ts` 管理标题、主题、音频场景及实施阶段
- `types.ts` 声明模块接收的运行上下文
- `module.test.ts` 校验轮次隔离、旧档、重复结算和重玩，可用 `npm run test -- src/modules/ending` 运行

正式剧情页面按本轮实际记录显示结果。点击「进入我的生日小屋」后，现有主线事务一次性记录轮次完成、首次寿星成就及永久权限，再由主控进入小屋。刷新结算页本身不会发奖。角色图替换方式见 [素材清单](../../../materials/ASSETS.md)。

# 接礼物

运行 `npm run dev` 后打开 [接礼物独立预览](http://127.0.0.1:5173/#/dev/catch-gifts)。[含历史成绩的调试场景](http://127.0.0.1:5173/#/dev/catch-gifts?scene=history) 可验证历史最高分显示。

点击开始后，在场地内左右拖动篮子，桌面也可按住左右方向键。接住礼物加分，工作消息和烦恼减分，最低为零。只计前台 30 秒，切到后台会暂停，回来后点「继续接礼物」。一局结束后，成绩与成就原子写入，已结算成绩可在刷新后恢复。退出尚未玩完的一局后，可重新开始。

- `Module.vue` 管理前后台计时、成绩恢复、结算反馈和模块完成事件
- `CatchField.vue` 与 `CatchProp.vue` 绘制场景、篮子、角色和道具，处理触屏与键盘输入
- `game.ts` 负责掉落时间表、碰撞、称号和成就达成计算，`config.ts` 定义各类道具与场地参数
- `module.test.ts` 验证不同刷新率、计分及称号边界，可用 `npm run test -- src/modules/catch-gifts` 运行

0 分也可完成本关，继续后进入主线的默契问答。两关共用游乐场章节奖励，独立调试或收藏玩法只保存结果和成就。角色素材接入见 [素材说明](../../../materials/ASSETS.md)。

# 生日蛋糕屋

运行 `npm run dev`，打开 [蛋糕屋独立预览](http://127.0.0.1:5173/#/dev/cake-shop)。

在制作台用色样选择蛋糕胚和奶油，再点水果或装饰贴纸摆上蛋糕。直接拖动装饰，或在「微调装饰」用方向按钮、旋转和缩放滑杆调整。完成制作后选择普通或数字蜡烛，数字由本人填写。点亮进入烛光暗场，手动吹灭后亮灯并播放礼花。也可主动授权麦克风，本地只分析音量。离开页面或切到后台会释放麦克风。

- `Module.vue` 负责编辑、点灯流程及完成事件
- `CakeArtwork.vue` 与 `CakePiece.vue` 绘制蛋糕、装饰和蜡烛，导出使用同一画面
- `CakeScene.vue` 绘制工作台和烛光暗场，并切换小白、小金毛的制作、等点灯、许愿和庆祝动作
- `config.ts` 管理配色、可选装饰、上限及许愿文案；`cake.ts` 管理摆放、蜡烛数字和阶段恢复
- `useBlowDetector.ts` 管理可选麦克风授权、实时音量判断和资源清理

草稿随编辑写入。首次成功吹灭后原子保存作品与甜点大师成就，再吹一次会使用已保存的同一件作品。开发和收藏玩法不发剧情币。若在许愿时离开且成品尚未保存，恢复后先从未点亮的蜡烛继续。线条小狗插牌等授权素材接入后在正式版开放。

`npm run test -- src/modules/cake-shop` 校验装饰上限、调节边界、空数字及流程恢复。

本地预览角色图位于 `materials/dogs/cake-shop/`，可同名替换。网页可用素材通过共享 `assets.dogs` 中的 `cake-make`、`cake-ready`、`cake-wish`、`cake-cheer` 和可选 `cake-topper` 接入。来源见 [素材说明](../../../materials/ASSETS.md)。
